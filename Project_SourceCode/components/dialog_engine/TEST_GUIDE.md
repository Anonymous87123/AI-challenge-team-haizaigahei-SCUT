# 智能对话系统 - 测试验证指南

## 🧪 测试环境准备

### 前置条件
- ✅ Web服务器已启动（推荐使用 `start.bat` 或 `start.sh`）
- ✅ 浏览器支持JavaScript（推荐Chrome/Firefox最新版本）
- ✅ 网络连接正常（需要访问CDN资源）

### 测试步骤

1. 启动应用
   ```bash
   # Windows
   cd Project_SourceCode
   start.bat
   
   # 或使用Node.js
   node -e "require('http').createServer((req, res) => {res.writeHead(200); require('fs').readFileSync(__dirname + '/campus-ai-assistant.html', (err, data) => res.end(data))}).listen(8080)"
   ```

2. 打开浏览器
   - 访问 `http://localhost:8080` 或相应的本地服务器地址
   - 等待页面完全加载

3. 登录系统
   - 使用测试账号登录（如：学号20210001，密码123456）
   - 或选择游客模式
