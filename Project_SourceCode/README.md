## 📖 项目简介

校园AI助手是一款专为大学生设计的智能校园生活服务平台，旨在解决校园信息分散、社交渠道有限、学习任务管理混乱等痛点。通过集成AI智能问答、校园社交、学习管理、生活服务等功能，为学生提供便捷、高效的一站式校园解决方案。

### 🎯 核心价值

- **一站式服务**：将校园信息查询、社交互动、学习管理集成在同一平台，无需切换多个应用
- **智能问答**：基于自然语言处理的AI助手，快速响应校园相关问题和查询
- **社交互动**：校园墙 + 发现朋友系统，建立校园社交网络，拓展人际关系
- **离线可用**：PWA技术支持，安装后可离线使用，在线时自动同步数据
- **跨平台**：支持桌面端和移动端，适配各种设备，随时随地进行校园生活管理

### 👥 目标用户

- 大学本科生（18-25岁）
- 研究生及博士生
- 需要高效管理校园生活的学生群体
- 希望拓展校园社交圈的学生
- 需要学习计划管理和任务提醒的学生

### 💡 应用场景

| 场景分类 | 具体应用 | 解决的问题 |
|---------|---------|-----------|
| 📚 学习管理 | 课程表查询、作业提醒、考试安排 | 学习时间管理混乱，容易错过重要事项 |

## 🚀 核心功能

### 🤖 智能对话系统

#### 功能概述

智能对话系统是校园AI助手的核心功能，通过自然语言处理技术，为学生提供智能问答服务。系统集成智能对话引擎v3.0，支持多场景对话、个性化回复、上下文理解、多轮对话、实体抽取等高级功能。

#### 技术架构

**对话引擎核心组件**：
1. **对话引擎** (`dialog_engine.js`) - 主控制器，协调所有对话相关组件
2. **实体抽取模块** (`entity_extractor.js`) - 自动提取作业、课程、时间等关键信息
3. **对话状态机** (`dialog_state_machine.js`) - 管理复杂的多轮对话流程
4. **响应生成器** (`response_generator.js`) - 基于实体的智能响应生成
5. **人格选择器** (`personality_selector.js`) - 选择AI人格类型
6. **用户画像** (`user_profiles.json`) - 5种详细的人格配置

#### 主要特性

- ✅ **自然语言输入**：支持多样化提问方式，无需特定格式
- ✅ **意图识别**：支持20+种意图类型（识别准确率>90%）
- ✅ **实体抽取**：自动提取作业名称、课程名称、截止日期、地点、时间范围等关键信息
- ✅ **多轮对话**：支持多轮对话状态管理、实体收集与验证、智能澄清与引导
- ✅ **多领域覆盖**：
  - **校园服务**：食堂菜单、图书馆信息、校车时刻表、快递查询、场馆信息
  - **学习管理**：课程表查询、作业提醒、考试安排、教室位置
  - **生活服务**：体育馆开放时间、校医院信息、打印点、校园活动
  - **智能对话**：打招呼（时间感知）、学习讨论、兴趣爱好、情感支持
- ✅ **Markdown渲染**：AI回答支持Markdown格式，美化显示效果
- ✅ **聊天记录**：自动保存历史对话，支持历史查询和快捷回复
- ✅ **智能建议**：输入时自动显示常用问题建议
- ✅ **个性化响应**：根据用户画像（5种人格类型）生成个性化回复
- ✅ **响应时间**：平均响应时间<2秒

每个JSON文件包含：

- `sample_conversations`: 示例对话
- `context_requirements`: 上下文要求
- `subject_mapping`: 学科映射表（仅学习讨论类）

#### 多轮对话状态管理

**对话状态机 (DialogStateMachine)** 功能：

- **状态追踪**：
  - `currentIntent`: 当前意图
  - `waitingFor`: 等待用户提供的实体列表
  - `collectedEntities`: 已收集的实体对象
  - `conversationHistory`: 对话历史记录
  - `isDialogActive`: 对话是否处于活跃状态
  - `progress`: 对话完成进度（0-1）

- **支持的多轮意图**：
  - `add_homework`: 添加作业（需要：作业名称、截止日期）
  - `set_reminder`: 设置提醒（需要：提醒时间）
  - `query_homework`: 查询作业（可筛选课程、时间）
  - `ask_schedule`: 询问课程表（可筛选时间）

- **智能澄清机制**：
  - 自动检测缺失的必需实体
  - 智能询问用户缺失信息
  - 实体验证与完整性检查
  - 友好的错误提示和引导

**多轮对话流程示例**：

```

第1轮：

  - 已收集实体：{course_name: "高等数学", homework_name: "完成习题册第5章"}

  - 进度：2/3 (67%)

第3轮：
用户：后天截止

  - 已收集实体：{course_name: "高等数学", homework_name: "完成习题册第5章", due_date: "后天"}

  - 对话完成

#### 实体抽取详情

**实体抽取器 (EntityExtractor)** 支持的实体类型：

| 实体类型 | 描述 | 示例 | 自动映射规则 |
|---------|------|------|-------------|
| `homework_name` | 作业名称 | "完成习题册第5章" | 识别作业、论文、报告、作业本等关键词 |
| `due_date` | 截止日期 | "后天"、"本周五"、"3天后" | 支持相对时间和绝对时间 |
| `course_name` | 课程名称 | "高数"、"英语" | 智能映射：高数→高等数学、大英→大学英语 |
| `note` | 备注信息 | "注意格式要求" | 提取引号内容、逗号后说明 |
| `time_range` | 时间范围 | "本周"、"下周"、"今天" | 支持多种时间表达方式 |
| `reminder_time` | 提醒时间 | "提前1天"、"明天上午9点" | 支持提前时间和具体时间 |
| `location` | 地点信息 | "二食堂"、"理科楼A301" | 识别所有校园地点 |
| `activity_type` | 活动类型 | "游泳"、"健身"、"学习" | 识别运动和学习活动 |

### 🏫 校园墙社交系统

#### 功能概述

校园墙是一个开放式的社交平台，学生可以发布帖子、分享生活、交流互动。系统支持瀑布流布局、点赞收藏、评论回复等功能，还提供128+ Emoji表情选择器，增强互动体验。

#### 主要特性

- ✅ **瀑布流布局**：自适应的瀑布流展示帖子，美观高效
- ✅ **发布帖子**：支持文字内容 + 图片URL（通过Markdown插入图片）
- ✅ **点赞系统**：带心跳动画效果的点赞功能，实时统计点赞数
- ✅ **收藏系统**：星形图标收藏，可在个人中心的"我的收藏"查看
- ✅ **评论系统**：
  - 128+ Emoji表情选择器（8个分类：笑脸、手势、爱心、动物、食物、活动、物品、符号）
  - 支持回复他人评论
  - 支持嵌套回复（子回复缩进显示）
  - 按时间/热度排序
  - 楼主（帖子作者）特殊标识（👑）
- ✅ **社交互动**：
  - 从帖子可以添加好友
  - 直接发送消息与好友聊天
  - 查看用户档案
- ✅ **帖子筛选**：支持按类型（全部、学习、生活、娱乐）筛选帖子
- ✅ **个人收藏中心**：统一查看所有收藏的帖子
- ✅ **帖子类型标签**：学习、生活、娱乐三种类型
- ✅ **发布时间显示**：显示相对时间（如"刚刚"、"5分钟前"、"1小时前"）
- ✅ **点赞防抖机制**：300ms防抖，防止重复点击
- ✅ **点赞持久化**：点赞状态保存到LocalStorage
- ✅ **评论分页加载**：支持分页加载评论

#### 使用方法

**步骤1：浏览校园墙**
```
1. 点击左侧导航栏"校园墙"按钮
2. 自动加载瀑布流布局的帖子列表
3. 滚动查看更多帖子
4. 点击帖子可查看详情
5. 使用顶部筛选器切换帖子类型（全部/学习/生活/娱乐）
```

**步骤2：发布帖子**
```
1. 点击右上角"发布帖子"按钮
2. 输入帖子内容（支持Markdown格式）
3. 可选：插入图片URL，格式为：
   ![图片描述](https://example.com/image.jpg)
4. 选择帖子类型（学习/生活/娱乐）
5. 点击"发布"按钮
6. 帖子立即显示在校园墙顶部
```

**步骤3：点赞收藏**

**点赞功能**：
```
1. 点击帖子底部的爱心图标
2. 点赞数自动+1
3. 触发心跳动画效果（1.5秒）
4. 点赞状态保存到LocalStorage
5. 刷新后点赞状态保持
6. 按钮变色（红色）表示已点赞
7. 再次点击可取消点赞（300ms防抖）
```

**点赞技术细节**：
- 防抖时间：300ms
- 动画时长：1.5秒
- 持久化：LocalStorage
- 动画效果：CSS `@keyframes heartBeat`
- 颜色变化：灰色→红色 (#e74c3c)

**收藏功能**：
```
1. 点击帖子底部的星形图标
2. 提示"已添加到收藏"
3. 显示收藏成功动画
4. 可在侧边栏"我的收藏"查看所有收藏
5. 再次点击可取消收藏
```

**步骤4：评论互动**
```
【发表评论】
1. 点击帖子标题进入详情页
2. 在评论输入框输入评论内容
3. 点击Emoji按钮打开表情选择器
4. 选择分类：笑脸、手势、爱心、动物、食物、活动、物品、符号
5. 点击表情插入到输入框
6. 点击"发送"发布评论
7. 评论按时间倒序显示

【回复评论】
1. 点击他人的评论
2. 显示"回复"提示
3. 在回复框输入回复内容
4. 发送后回复以缩进形式显示
5. 自动@目标用户
6. 回复显示层级关系（最多支持2级）

【嵌套回复】
原始评论：
  └─ 一级回复（缩进2个空格）
      └─ 二级回复（缩进4个空格）

【楼主标识】
- 帖子作者的所有评论显示👑标识
- 方便识别原创者回复
```

**步骤5：社交互通**

**添加好友**：
```

2. 显示Toast提示："已发送好友请求"

4. 1.5秒后自动刷新
5. 显示"已成为好友"提示

```

3. 可开始一对一聊天
4. 聊天记录保存

```

- ✅ **导出聊天记录**：导出为TXT格式
- ✅ **导出所有数据**：导出为JSON格式
- ✅ **自动数据备份**：定期自动备份数据
- ✅ **数据清除**：清空所有应用数据
- ✅ **数据导入**：从备份文件恢复数据

#### 导出功能

**导出聊天记录**：
```
1. 点击设置→数据管理
2. 选择"导出聊天记录"
3. 格式选择：TXT
4. 点击"导出"
5. 自动下载chat_history.txt
6. 文件内容格式：
   [2024-01-15 10:30:00] 用户：你好
   [2024-01-15 10:30:05] AI：你好！有什么可以帮你的吗？
   [2024-01-15 10:31:00] 用户：食堂今天有什么菜？
   [2024-01-15 10:31:02] AI：正在查询今日菜单...
```

**导出所有数据**：
```
1. 点击设置→数据管理
2. 选择"导出所有数据"
3. 格式选择：JSON
4. 点击"导出"
5. 自动下载campus_ai_backup.json
6. 文件内容包含：
   - 用户信息
   - 聊天记录
   - 课程表
   - 校园墙帖子
   - 好友列表
   - 收藏内容
   - 应用设置
```

#### 数据备份

**自动备份**：
- 备份频率：每天一次
- 备份时间：凌晨3点
- 备份位置：LocalStorage
- 备份保留：最近7天的备份

**手动备份**：
```
1. 点击设置→数据管理
2. 点击"立即备份"
3. 显示"备份成功"提示
4. 备份保存到LocalStorage
```

#### 数据导入恢复

**从备份恢复**：
```
1. 点击设置→数据管理
2. 点击"导入备份"
3. 选择备份文件（JSON格式）
4. 点击"导入"
5. 显示"导入成功"提示
6. 刷新页面查看恢复的数据
```

#### 数据清除

**清空所有数据**：
```
1. 点击设置→数据管理
2. 点击"清空数据"
3. 显示警告提示："确定要清空所有数据吗？此操作不可撤销"
4. 点击"确定"确认
5. 显示"数据已清空"
6. 自动刷新页面
```

**选择性清除**：
```
- 清空聊天记录：仅删除聊天记录
- 清空课程表：仅删除课程表数据
- 清空缓存：仅删除缓存文件
- 重置设置：仅重置应用设置
```

### 对话引擎架构

**数据流程**：
```
用户输入
    ↓
意图识别（20+种意图类型）
    ↓
实体抽取（作业、课程、时间等）
    ↓
情感分析
    ↓
是否多轮对话？
    ├─ 是 → 对话状态机管理 → 收集实体 → 询问缺失信息
    └─ 否 → 继续
    ↓
对话场景选择
    ↓
响应生成器生成响应
    ├─ 填充实体占位符
    ├─ 应用用户画像
    └─ 添加情感与表情
    ↓
上下文优化
    ↓
最终响应生成
```

**模块关系**：
```
campus-ai-assistant.html (主界面)
    ↓
ChatModule (聊天模块)
    ↓
DialogEngine (对话引擎)
    ↓
    ├─ EntityExtractor (实体抽取)
    ├─ DialogStateMachine (状态机)
    ├─ ResponseGenerator (响应生成)
    ├─ Dialog Data (对话数据)
    │   ├─ 作业管理
    │   ├─ 课程查询
    │   ├─ 提醒设置
    │   ├─ 校园生活
    │   ├─ 学习场景
    │   ├─ 兴趣爱好
    │   └─ 情感支持
    └─ User Profiles (用户画像)
```

### PWA架构

**Service Worker生命周期**：
```
1. 注册 (register)
   ↓
2. 安装 (install)
   ↓
3. 激活 (activate)
   ↓
4. 运行 (fetch)
```

**缓存策略**：
- **静态资源**：Cache First（优先使用缓存）
- **API数据**：Network First（优先使用网络）
- **图片资源**：Stale While Revalidate（后台更新缓存）

## ❓ 常见问题

### Q1: 为什么我无法登录？

**解决方案**：
- 演示模式可以输入任意8位数字作为学号
- 密码可以任意输入
- 如果仍无法登录，尝试刷新页面

### Q2: AI回复为什么有时候不准确？

**说明**：
- 本项目使用轻量级前端对话引擎，不是真实的AI
- 基于规则和模板的匹配，准确性有限
- 支持的关键词和意图类型有限，超出范围可能无法识别
- 建议使用标准、清晰的自然语言提问

### Q3: 数据会保存吗？

**保存位置**：
- 所有数据保存在浏览器的LocalStorage中
- 数据仅在当前浏览器中有效
- 清除浏览器数据会清除应用数据
- 建议定期导出数据进行备份

### Q4: 如何离线使用？

**离线功能**：
- 首先在线访问应用并安装PWA
- Service Worker会自动缓存资源
- 断网后仍可浏览缓存内容
- 离线时无法发送消息和发布帖子

### Q5: 如何备份和恢复数据？

**备份流程**：
1. 点击设置→数据管理
2. 选择"导出所有数据"
3. 下载JSON备份文件
4. 保存到安全位置

**恢复流程**：
1. 点击设置→数据管理
2. 点击"导入备份"
3. 选择之前导出的JSON文件
4. 点击"导入"恢复数据

### Q6: 快捷方式如何使用？

**使用快捷方式**：
- 安装PWA后，会在桌面/主屏创建快捷方式
- 直接点击快捷方式可快速启动应用
- 支持的快捷方式：
  - 查看课程表
  - 咨询AI
  - 查看消息

### Q7: 支持哪些浏览器？

**推荐浏览器**：
- Chrome 90+（最佳体验）
- Edge 90+（最佳体验）
- Firefox 88+（支持大部分功能）
- Safari 14+（支持大部分功能）

**不支持的浏览器**：
- IE 11及以下
- 旧版本浏览器
