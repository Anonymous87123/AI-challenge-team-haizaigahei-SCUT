## 📖 项目简介

校园AI助手是一款专为大学生设计的智能校园生活服务平台，旨在解决校园信息分散、社交渠道有限、学习任务管理混乱等痛点。通过集成AI智能问答、校园社交、学习管理、生活服务等功能，为学生提供便捷、高效的一站式校园解决方案。

### 🎯 核心价值

- **一站式服务**：将校园信息查询、社交互动、学习管理集成在同一平台，无需切换多个应用
- **智能问答**：基于自然语言处理的AI助手，快速响应校园相关问题和查询
- **社交互动**：校园墙 + 发现朋友系统，建立校园社交网络，拓展人际关系
- **离线可用**：PWA技术支持，安装后可离线使用，在线时自动同步数据
- **跨平台**：支持桌面端和移动端，适配各种设备，随时随地进行校园生活管理

### 👥 目标用户

- 大学本科生（18-25岁）
- 研究生及博士生
- 需要高效管理校园生活的学生群体
- 希望拓展校园社交圈的学生
- 需要学习计划管理和任务提醒的学生

### 💡 应用场景

| 场景分类 | 具体应用 | 解决的问题 |
|---------|---------|-----------|
| 📚 学习管理 | 课程表查询、作业提醒、考试安排 | 学习时间管理混乱，容易错过重要事项 |
| 🍽️ 生活服务 | 食堂菜单、图书馆信息、校车时刻表 | 校园信息分散，查询不便 |
| 🏟️ 场馆服务 | 体育馆、游泳馆等场地预约 | 场地信息不透明，预约流程复杂 |
| 💬 社交互动 | 校园墙发帖、评论、点赞收藏 | 校园社交渠道单一，交流不便 |
| 👥 朋友发现 | 基于兴趣匹配的好友推荐 | 社交圈有限，难以找到志同道合的朋友 |
| 💾 数据管理 | 聊天记录导出、课程表管理 | 数据分散，难以统一管理和备份 |

## ✨ 创新亮点

### 1. 轻量级AI问答系统
- **技术特点**：无需接入真实AI API，纯前端实现智能响应
- **核心优势**：响应速度快、无需网络、无API调用成本
- **支持场景**：智能对话引擎，支持打招呼、学习、娱乐、情感支持等多场景对话

- **社交流程**：浏览帖子 → 点赞 → 收藏 → 评论 → 回复 → 加好友 → 私信

- **匹配算法**：基于用户画像（年级、专业、兴趣标签）进行智能匹配
- **个性化推荐**：计算匹配度评分（如85%、92%），推荐最合适的好友
- **兴趣标签**：支持自定义兴趣标签，精准匹配志同道合的同学

### 4. 模块化架构设计
- **代码结构**：清晰的模块划分（chat.js, login.js, sidebar.js, pwa.js, utils.js）
- **易于扩展**：新功能模块可独立开发和集成
- **代码复用**：工具函数库统一管理，提高开发效率

## 🚀 核心功能

### 🤖 智能对话系统

#### 功能概述
智能对话系统是校园AI助手的核心功能，通过自然语言处理技术，为学生提供智能问答服务。系统集成智能对话引擎，支持多场景对话、个性化回复、上下文理解等功能。

#### 主要特性
- ✅ **自然语言输入**：支持多样化提问方式，无需特定格式
- ✅ **智能匹配**：基于FAQ知识库和对话引擎的智能响应
- ✅ **多领域覆盖**：
  - **校园服务**：食堂菜单、图书馆信息、校车时刻表、快递查询
  - **学习管理**：课程表查询、作业提醒、考试安排
  - **生活服务**：体育馆开放时间、校医院信息、校园活动公告
  - **智能对话**：打招呼、学习讨论、兴趣爱好、情感支持
- ✅ **Markdown渲染**：AI回答支持Markdown格式，美化显示效果
- ✅ **聊天记录**：自动保存历史对话，支持历史查询和快捷回复
- ✅ **智能建议**：输入时自动显示常用问题建议

#### 使用方法

**步骤1：启动对话**
```
1. 登录应用后，默认进入智能对话界面
2. 在输入框中输入问题
3. 点击发送按钮或按Enter键发送
```

**校园服务查询**

### 🏫 校园墙社交系统

#### 功能概述
校园墙是一个开放式的社交平台，学生可以发布帖子、分享生活、交流互动。系统支持瀑布流布局、点赞收藏、评论回复等功能，还提供128+ Emoji表情选择器，增强互动体验。

#### 主要特性
- ✅ **瀑布流布局**：自适应的瀑布流展示帖子，美观高效
- ✅ **发布帖子**：支持文字内容 + 图片URL（通过Markdown插入图片）
- ✅ **点赞系统**：带心跳动画效果的点赞功能，实时统计点赞数
- ✅ **收藏系统**：星形图标收藏，可在个人中心的"我的收藏"查看
- ✅ **评论系统**：
  - 128+ Emoji表情选择器（8个分类：笑脸、手势、爱心、动物、食物、活动、物品、符号）
  - 支持回复他人评论
  - 支持嵌套回复（子回复缩进显示）
  - 按时间/热度排序
  - 楼主（帖子作者）特殊标识（👑）
- ✅ **社交互动**：
  - 从帖子可以添加好友
  - 直接发送消息与好友聊天
  - 查看用户档案
- ✅ **帖子筛选**：支持按类型（全部、学习、生活、娱乐）筛选帖子
- ✅ **个人收藏中心**：统一查看所有收藏的帖子

#### 使用方法

**步骤1：浏览校园墙**
```
1. 点击左侧导航栏"校园墙"按钮
2. 自动加载瀑布流布局的帖子列表
3. 滚动查看更多帖子
4. 点击帖子可查看详情
```

**步骤2：发布帖子**
```
1. 点击右上角"发布帖子"按钮
2. 输入帖子内容（支持Markdown格式）
3. 可选：插入图片URL，格式为：
   ![图片描述](https://example.com/image.jpg)
4. 选择帖子类型（学习/生活/娱乐）
5. 点击"发布"按钮
```

**步骤3：点赞收藏**
```
点赞：
1. 点击帖子底部的爱心图标
2. 点赞数自动+1
3. 再次点击可取消点赞
4. 点赞时显示心跳动画效果

收藏：
1. 点击帖子底部的星形图标
2. 提示"已添加到收藏"
3. 可在侧边栏"我的收藏"查看所有收藏
```

**步骤4：评论互动**
```
1. 点击帖子查看详情
2. 在评论输入框输入评论内容
3. 点击Emoji按钮打开表情选择器
4. 选择表情增强表达
5. 点击"发送"发布评论
6. 点击他人的评论可进行回复
7. 回复会以缩进形式显示，@目标用户
```

**步骤5：社交互通**
```
添加好友：
1. 在帖子详情右上角点击"加好友"按钮
2. 显示"已发送好友请求"提示
3. 1.5秒后自动刷新，显示"已成为好友"
4. 按钮自动变为"发消息"

发消息：
1. 点击"发消息"按钮
2. 打开与该用户的聊天窗口
3. 可开始一对一聊天
```

### 👥 发现朋友系统

#### 功能概述
发现朋友系统基于用户画像进行智能匹配，帮助学生拓展校园社交圈。系统通过分析用户的年级、专业、兴趣标签等信息，推荐最匹配的好友候选。

#### 主要特性
- ✅ **智能推荐算法**：基于用户画像（年级、专业、兴趣标签）计算匹配度
- ✅ **匹配度评分**：显示百分比匹配度（如85%、92%），直观展示推荐质量
- ✅ **用户档案系统**：
  - 用户名、年级、专业信息
  - 彩色兴趣标签（可自定义）
  - 个人签名和头像（首字母渐变）
- ✅ **好友管理**：
  - 查看好友列表
  - 发送好友请求
  - 删除好友
- ✅ **实时消息**：好友请求、新消息实时通知
- ✅ **用户搜索**：支持按用户名搜索用户

#### 使用方法

**步骤1：查看推荐好友**
```
1. 点击左侧导航栏"发现朋友"按钮
2. 系统自动加载推荐好友列表
3. 每个好友卡片显示：
   - 用户头像（首字母渐变）
   - 用户名、年级、专业
   - 兴趣标签（彩色标签）
   - 匹配度评分（如85%）
4. 点击"查看档案"查看详细信息
```

**步骤2：添加好友**
```
1. 在好友卡片上点击"加好友"按钮
2. 显示"已发送好友请求"提示
3. 系统自动添加到好友列表
4. 按钮变为"发消息"
```

**步骤3：发起聊天**
```
方式一：从发现朋友添加
1. 点击"发消息"按钮
2. 打开聊天窗口
3. 输入消息开始聊天

方式二：从校园墙添加
1. 在帖子详情点击"加好友"
2. 好友添加后点击"发消息"
3. 直接开始聊天

方式三：查看好友列表
1. 点击侧边栏"消息"按钮
2. 查看所有好友列表
3. 点击好友名称打开聊天窗口
```

### 📊 个人成长仪表盘

#### 功能概述
个人成长仪表盘帮助学生追踪学习数据，评估能力水平，规划学习目标。通过可视化图表展示学习时长、技能分布、成长时间线等信息。

#### 主要特性
- ✅ **本月学习报告**：
  - 总学习时长（小时）
  - 增长率（与上月对比）
  - 平均成绩
  - 班级排名
- ✅ **技能雷达图**：
  - 六边形可视化展示
  - 6个维度：学习能力、实践能力、创新能力、健康管理、团队协作、社交能力
  - 蓝色（当前水平）vs 红色虚线（上月水平）对比
- ✅ **成长时间线**：
  - 按日期记录每日活动
  - 多种活动类型图标（学习、运动、社交、阅读等）
  - 一周活动记录展示
- ✅ **学期目标进度**：
  - 四大目标：阅读、社交、健康、技能
  - 不同颜色进度条区分
  - 完成百分比显示
  - 超预算警告（红色）
- ✅ **导出报告**：一键导出PDF格式成长报告

#### 使用方法

**步骤1：查看仪表盘**
```
1. 点击左侧导航栏"我的成长"按钮（带黄色New标签）
2. 自动打开成长仪表盘模态框
3. 查看四大模块：
   - 本月学习报告卡片
   - 技能雷达图
   - 成长时间线
   - 学期目标进度条
```

**步骤2：解读技能雷达图**
```
- 六边形形状：6个维度能力分布
- 蓝色实线：当前能力水平
- 红色虚线：上月能力水平（对比参考）

#### 主要特性
- ✅ **应用安装**：可安装到桌面/手机，像原生应用使用
- ✅ **离线缓存**：Service Worker 离线缓存，无网络也可访问
- ✅ **在线/离线检测**：自动检测网络状态
- ✅ **数据同步**：在线时自动同步数据
- ✅ **跨平台**：支持Windows、macOS、Linux、Android、iOS

#### 使用方法

**步骤1：安装PWA应用**
```
Chrome/Edge浏览器：
1. 在浏览器中访问应用
2. 地址栏右侧出现安装图标（⊕）
3. 点击安装图标
4. 确认安装
5. 应用添加到桌面或开始菜单

Firefox浏览器：
1. 点击地址栏右侧菜单
2. 选择"安装此站点为应用"
3. 确认安装
```

**步骤2：离线使用**
```
1. 首次访问时，应用自动缓存资源
2. 断网后仍可访问已缓存的界面
3. 离线时可使用所有功能
4. 数据保存在本地，不会丢失
```

**步骤3：数据同步**
```
1. 重新联网后，应用自动检测更新
2. 如果有新数据，自动同步
3. 提示"数据已同步"
4. 最新数据可正常使用
```

      → initializeData()          // 初始化数据
      → registerModules()         // 注册模块
      → initializePWA()           // 初始化PWA
      → checkLoginStatus()        // 检查登录状态
      → bindGlobalEvents()        // 绑定全局事件

// 对话引擎流程
DialogEngine.generateResponse(userInput)
  → analyzeIntent()              // 分析意图
  → extractEntities()            // 抽取实体
  → selectPersonality()          // 选择性格
  → generateContextResponse()     // 生成上下文响应
  → formatResponse()              // 格式化响应
```

## 🔧 常见问题

### Q1: 直接打开HTML文件无法使用某些功能？

**A**: 由于浏览器安全限制，PWA Service Worker等功能需要通过HTTP/HTTPS协议访问。建议使用本地服务器运行：

```bash
# 使用Python启动服务器
python -m http.server 8000

# 或使用Node.js
http-server -p 8000
```

### Q2: 数据是否会被清除？

**A**: 所有数据存储在浏览器LocalStorage中。
- 清除浏览器数据会丢失
- 使用隐私模式会丢失
- 更换浏览器会丢失

**建议**：定期使用"导出数据"功能备份。

### Q3: 支持多人同时使用吗？

**A**: 当前为纯前端应用，数据存储在本地浏览器中。
- 不支持跨设备同步
- 每个用户在各自浏览器中独立使用
- 多人使用需要各自运行应用

### Q4: 如何接入真实的AI API？

**A**: 在`components/chat.js`的`sendMessage`函数中，将关键词匹配逻辑替换为真实AI API调用：

```javascript
// 原逻辑
const response = DialogEngine.generateResponse(message);

// 替换为真实AI API
const response = await fetchAIResponse(message);

async function fetchAIResponse(message) {
  const response = await fetch('https://api.example.com/chat', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ message })
  });
  return await response.json();
}
```

### Q5: PWA安装后如何更新？

**A**: PWA会自动检测更新：
1. 打开应用时自动检查更新
2. 如有新版本，通知栏显示提示
3. 点击"更新"按钮完成更新
4. 更新后自动刷新页面

### Q6: 如何重置所有数据？

**A**: 
```
1. 点击"设置" → "数据管理"
2. 点击"清空所有数据"
3. 输入"确认"文字
4. 点击"确认清空"按钮
5. 警告：此操作不可恢复！
```

### Q7: 为什么有些功能不显示？

**A**: 可能原因：
1. 浏览器版本过低（升级到Chrome 90+）
2. JavaScript被禁用（在浏览器设置中启用）
3. LocalStorage被禁用（清除浏览器限制）
4. 未登录（登录后使用全部功能）

### Q8: 如何添加自定义问题？

**A**: 在`data/faq.json`中添加：

```json
{
  "intents": {
    "custom_question": {
      "keywords": ["关键词1", "关键词2"],
      "responses": ["回答1", "回答2"]
    }
  }
}
```

### Q9: 如何修改AI回复风格？

**A**: 在`components/dialog_engine/dialog_data/`目录下修改对应的JSON文件，调整响应模板。

### Q10: 应用崩溃了怎么办？

**A**: 
```
1. 按F12打开浏览器控制台
2. 查看错误信息
3. 清除浏览器缓存和LocalStorage
4. 刷新页面重新加载
5. 如问题持续，请提交Issue
```
