## 三、截图操作指南

### 方法一：使用系统截图工具

#### Windows
1. **全屏截图**：`Win + Shift + S`
2. 选择截图区域（矩形截图）
3. 截图后自动复制到剪贴板，粘贴到画图工具保存

#### macOS
1. **全屏截图**：`Command + Shift + 3`
2. **区域截图**：`Command + Shift + 4`
3. 截图自动保存到桌面

#### Linux
1. **全屏截图**：`Print Screen` 或 `PrtSc`
2. **区域截图**：`Shift + Print Screen`

---

### 方法二：使用浏览器截图扩展（推荐）

推荐使用以下扩展：

#### Firefox Screenshots（Firefox 内置）
1. 点击地址栏右侧的截图图标
2. 选择"截取可见部分"或"保存整个页面"
3. 下载 PNG 格式

#### 截图插件（Chrome/Edge）
- Awesome Screenshot
- GoFullPage
- Fireshot

**优点**：
- 自动隐藏浏览器地址栏
- 支持整页长截图
- 批量截图方便

---

### 方法三：使用截图软件

推荐专业截图工具：

- **Snipaste**（Windows/macOS，免费，强烈推荐）
  - 快捷键：`F1` 截图，`F3` 贴图
  - 自动检测 UI 元素边框
  - 支持标注和箭头

- **ShareX**（Windows，免费开源）
  - 功能强大
  - 支持快捷键配置

- **iShot**（macOS，免费）
  - 简洁好用
  - 支持滚动截图

## 五、截图质量要求

### 分辨率要求
- **桌面端截图**：建议 1920×1080 或更高
- **移动端截图**：建议 375×667（iPhone SE）或 414×896（iPhone 11）
- **文件格式**：PNG（推荐）或 JPG

### 图片质量
- **清晰度**：文字清晰可读，无模糊
- **压缩**：适当压缩但不过度（文件大小建议 500KB - 2MB）
- **裁剪**：适当裁剪浏览器边框，突出内容

### 颜色模式
- **RGB 模式**：确保颜色鲜活
- **避免**：CMYK 模式（可能导致颜色偏差）
