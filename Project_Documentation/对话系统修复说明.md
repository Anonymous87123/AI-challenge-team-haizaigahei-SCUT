## 核心问题分析

### 1. 实体抽取问题（33%通过率）
**问题1**：将动作动词识别为homework_name
- 输入："添加英语作文作业" → 提取为"添加英语作文"（错误）
- 期望：应提取为"作业"或"作文作业"

**问题2**：将查询动词识别为homework_name
- 输入："查询我这周的作业" → 提取为"查询我这周的"（错误）
- 期望：应为null或不包含homework_name

### 2. 意图识别问题（83%通过率）
**问题1**：意图优先级不够明确
- "今天有什么课" → 识别为`course_query`而非`ask_schedule`
- "体育馆开放时间" → 识别为`ask_library`而非`ask_facility`
- "添加高数作业，周五截止" → 识别为`homework_management`而非`add_homework`

**根本原因**：多个意图共享trigger_keywords，导致通用意图（如homework_management）得分更高

### 3. 多轮对话问题（0%通过率）
**问题**：对话未按预期流程完成，过早中止

## 根本原因分析

### 1. 意图识别问题
**原因**：虽然主应用加载了对话数据，但意图映射不够精确。多个意图共享相同的`trigger_keywords`，导致意图识别可能选择错误的意图。

**具体表现**：
- `add_homework`和`query_homework`都映射到`homework_management`，共用trigger_keywords
- 意图识别可能将"添加作业"识别为`query_homework`

### 2. 多轮对话测试失败（关键问题）
**原因**：测试代码在每一步后都调用`DialogEngine.abortMultiTurnDialog()`，导致对话状态在每一步后被重置，无法进行真正的多轮对话。

**代码位置**：`intelligent_dialog_tests.js` 第255行
```javascript
// 错误的代码逻辑
for (let i = 0; i < dialogue.steps.length; i++) {
    const response = DialogEngine.getUserResponse(dialogue.steps[i]);
    
    // 检查响应是否包含预期内容
    if (!dialogue.expectedContains.every(text => response.text.includes(text))) {
        DialogEngine.abortMultiTurnDialog(); // ❌ 每步后都重置状态
    }
}
```

### 3. 实体抽取问题
**原因**：
- 作业名称提取不够精确
- 未移除课程名前缀（如"高数作业"应提取为"作业"而非"高数作业"）
- 缺少对章节号的识别（如"第三章习题"）

## 技术细节

### 意图识别算法

系统使用关键词匹配算法，步骤如下：

1. **快速匹配**：优先匹配特殊意图（thanks, goodbye）
2. **关键词评分**：为每个意图计算得分
   ```javascript
   for (const keyword of dialogData.trigger_keywords) {
       if (input.toLowerCase().includes(keyword.toLowerCase())) {
           score += keyword.length;
       }
   }
   ```
3. **选择最高分**：返回得分最高的意图

### 多轮对话状态机

状态结构：
```javascript
{
    intent: "add_homework",
    collectedEntities: {},
    waitingFor: ["homework_name", "due_date"],
    turnCount: 0,
    maxTurns: 5,
    conversationHistory: [],
    isComplete: false
}
```

完整流程：
1. `startDialog()` - 初始化对话状态
2. `processInput()` - 处理用户输入，提取实体
3. `askNextQuestion()` - 生成追问
4. `completeDialog()` - 生成确认信息

### 实体抽取策略

优先级：
1. 精确模式匹配（正则表达式）
2. 关键词匹配（作业类型）
3. 回退到默认值
