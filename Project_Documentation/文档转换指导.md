## 方法一：使用VS Code（推荐）

### 安装Markdown PDF插件

1. 打开VS Code
2. 点击左侧扩展图标（或按 `Ctrl+Shift+X`）
3. 在搜索框中输入 `Markdown PDF`
4. 安装由 `yzane` 开发的 `Markdown PDF` 插件

### 转换步骤

1. 在VS Code中打开需要转换的Markdown文件
2. 按 `Ctrl+Shift+P` 打开命令面板
3. 输入 `Markdown PDF: Export (pdf)` 并回车
4. 等待转换完成，PDF文件将保存在同一目录

### 自定义样式（可选）

在Markdown文件中添加以下代码块来自定义PDF样式：

```html
<style>
  /* PDF样式自定义 */
  body {
    font-family: "Microsoft YaHei", "PingFang SC", sans-serif;
    font-size: 14px;
    line-height: 1.8;
  }
  h1 {
    color: #2c3e50;
    border-bottom: 3px solid #3498db;
    padding-bottom: 10px;
  }
  h2 {
    color: #34495e;
    border-bottom: 2px solid #95a5a6;
    padding-bottom: 8px;
  }
  table {
    border-collapse: collapse;
    width: 100%;
    margin: 20px 0;
  }
  table th, table td {
    border: 1px solid #ddd;
    padding: 10px;
    text-align: left;
  }
  table th {
    background-color: #f8f9fa;
    font-weight: bold;
  }
  code {
    background-color: #f4f4f4;
    padding: 2px 6px;
    border-radius: 3px;
    font-family: "Consolas", "Monaco", monospace;
  }
  blockquote {
    border-left: 4px solid #3498db;
    padding-left: 15px;
    color: #555;
    margin: 20px 0;
  }
</style>
```

## 方法二：使用Pandoc命令行工具

### 安装Pandoc

1. 访问 https://pandoc.org/installing.html
2. 下载并安装Windows版本
3. 重启终端

### 转换命令

```bash
# 转换单个文件
pandoc "应用介绍.md" -o "应用介绍.pdf" --pdf-engine=xelatex -V CJKmainfont="Microsoft YaHei"

# 批量转换所有文档
for %f in (*.md) do pandoc "%f" -o "%~nf.pdf" --pdf-engine=xelatex -V CJKmainfont="Microsoft YaHei"
```

### 高级选项

```bash
# 指定页边距
pandoc "应用介绍.md" -o "应用介绍.pdf" --pdf-engine=xelatex \
  -V geometry:margin=2.5cm \
  -V CJKmainfont="Microsoft YaHei"

# 添加页码
pandoc "应用介绍.md" -o "应用介绍.pdf" --pdf-engine=xelatex \
  -V CJKmainfont="Microsoft YaHei" \
  -V numbersections=true \
  -V fontsize=12pt
```

## 方法三：使用在线转换工具

### 推荐工具

1. **Markdown2PDF** - https://markdown2pdf.com/
2. **CloudConvert** - https://cloudconvert.com/md-to-pdf
3. **MarkDown PDF** - https://www.markdownpdf.org/

### 使用步骤

1. 访问转换网站
2. 上传Markdown文件
3. 选择输出格式为PDF
4. 点击转换按钮
5. 下载生成的PDF文件

**注意：** 在线工具可能存在以下限制：
- 文件大小限制
- 格式兼容性问题
- 隐私风险（避免上传敏感信息）
- 中文支持可能不完整

## 方法四：使用Typora（最简单）

### 安装Typora

1. 访问 https://typora.io/
2. 下载并安装Windows版本
3. Typora已进入付费期（但可免费试用15天）

### 转换步骤

1. 在Typora中打开Markdown文件
2. 点击菜单栏 `文件` → `导出` → `PDF`
3. 保存PDF文件

### 主题配置

Typora提供多种主题，可在 `偏好设置` → `外观` → `主题` 中选择：
- Default（默认）
- Github
- Night
- ...

## 常见问题

### Q1: 中文显示乱码或方块
**解决方案：** 
- 确保系统已安装中文字体（如微软雅黑、宋体）
- Pandoc方法中指定 `-V CJKmainfont="Microsoft YaHei"`

### Q2: 表格格式错乱
**解决方案：** 
- 使用标准Markdown表格语法
- 在自定义样式中添加 `table` 样式规则

### Q3: 代码块格式不美观
**解决方案：** 
- 使用 ```language 指定语言高亮
- 在样式中自定义 `code` 和 `pre` 样式

### Q4: 图片无法显示
**解决方案：** 
- 确保图片路径正确（相对路径）
- 使用绝对路径或将图片放在与MD文件同一目录
